go-dataframe is the table library of the Go scientific stack built on go-ndarray: Series, DataFrame and Index, with selection, missing data, group-by, joins, reshaping and time series, a fast CSV reader, Arrow and Parquet, notebook display and plots. Numeric columns are go-ndarray arrays, handed out without copying. No Python, no cgo.

Why go-dataframe

The table operations notebooks are made of.

Reading a file, selecting, cleaning, grouping, joining, reshaping and plotting: each operation gives pandas' answer — values, dtypes, index and row order — under a Go name, and fallible calls return an error rather than raising.

🗂️

Series, DataFrame, Index

Typed columns sharing one index of row labels; Loc, Iloc, boolean filters and Query. Every value is immutable: operations share the columns they did not change.

🧩

Group-by, joins, reshaping

GroupBy with Agg, Merge and Concat, Pivot, PivotTable, Melt, Stack and Unstack.

🕒

Time series

ToDatetime, Resample, periods, the Dt accessor, Shift, Diff, CumSum and rolling windows.

📄

A fast CSV reader

Typed columns, column selection, row limits and dates parsed on request; about ten times pandas' C parser on ten million rows.

🏹

Arrow and Parquet

arrowio reads and writes Arrow IPC and Feather, parquetio Parquet, both over apache/arrow-go.

🧮

On go-ndarray

Numeric columns are go-ndarray arrays, handed out without copying: df.Values() is an *ndarray.Array.

📓

Notebook display and plots

Display gives a notebook the text and the HTML table; dfplot draws lines, bars, histograms, areas and scatter plots with go-plot.

⚖️

BSD-3-Clause

Memory is at par with pandas for numeric columns and worse for strings: a Go []string costs 16 bytes a value, where pandas 3 and polars use Arrow-style buffers. The benchmark table takes 400 MB here, 349 MB in pandas, 269 MB in polars.
